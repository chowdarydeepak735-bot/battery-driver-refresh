A practical, safety-first guide to checking and refreshing Windows battery devices on Windows 10 and Windows 11.

Windows 10 / 11

Before you begin

These are built-in Windows Plug and Play devices. Removing them is not guaranteed to fix a battery or charging problem, and Windows may reinstall them automatically.

Recommended: use Device Manager. Do not bypass Windows security or force-remove protected devices. Save your work before restarting.

What are these devices?

  • Microsoft ACPI-Compliant Control Method Battery — helps Windows receive battery status information from the computer firmware.
  • Microsoft AC Adapter — represents the AC power adapter connection to Windows.

Names and behavior can vary by computer manufacturer and Windows version.

Recommended method: Device Manager

  1. Save open files. Connect the laptop to its charger if available.
  2. Right-click Start and select Device Manager.
  3. Expand the Batteries category.
  4. Right-click Microsoft ACPI-Compliant Control Method Battery and choose Uninstall device, if Windows allows it.
  5. Usually, there is no need to uninstall Microsoft AC Adapter. Only do so when following a specific troubleshooting instruction.
  6. Restart normally using Start → Power → Restart.
  7. If the device does not reappear, open Device Manager and choose Action → Scan for hardware changes.

Windows normally detects the hardware and reinstalls its built-in device driver. If the device is still missing or an error remains, stop and check your laptop manufacturer's support guidance.

Optional PowerShell check (read-only)

This command lists detected battery-class devices. It does not uninstall anything, change settings, or restart the laptop. Open PowerShell and paste:

Get-PnpDevice -Class Battery |
  Format-Table Status, FriendlyName, InstanceId -AutoSize

Do’s and don’ts

Do

  • Save your work first.
  • Use Device Manager and normal Windows restart options.
  • Keep User Account Control (UAC) enabled.
  • Read administrator prompts before approving them.
  • Use your laptop maker’s support site if charging issues continue.

Don’t

  • Don’t disable UAC or automate clicking “Yes”.
  • Don’t bypass “Access is denied” with force or registry tricks.
  • Don’t delete driver-store packages for these devices.
  • Don’t repeatedly uninstall devices if Windows blocks the action.
  • Don’t run unknown scripts as Administrator.

Troubleshooting: “Access is denied”

pnputil /remove-device may return Access is denied even in an Administrator window. Windows can protect active system devices. Administrator mode does not guarantee that removal is permitted.

Stop rather than trying to bypass the restriction. Use Device Manager if available, or follow the laptop manufacturer's approved support procedure.
